设备告警导出工具（Windows 64 位）

使用步骤
1. 将整个压缩包解压到可写的普通文件夹，例如桌面；不要直接在压缩包中运行。
2. 编辑程序同目录的 SN.csv：无表头，每行一个逆变器 SN，例如：
   603J303048EP059
   重复 SN 自动去重，空行自动忽略；不要增加其他列。
3. 双击 FoxAlarmExport.exe，输入 FoxESS Cloud 账号和原始登录密码。
4. 可选“保存账号密码”。下次运行自动填入，可通过“清除已保存信息”删除。
5. 选择开始日期和结束日期，点击“开始查询并导出”。
6. 完成后点击“打开结果文件夹”。每次自动创建独立的 results_日期_时间 文件夹。

结果文件
告警列表.csv：序号、电站、逆变器SN、采集器SN、告警编号、告警内容、报错时间。
查询明细.csv：每个 SN 的状态、接口总数、本次导出数和失败/未完整导出原因。
失败SN.csv：仅查询失败的 SN，无表头，可复制内容到 SN.csv 后重新查询。
运行日志.log：本次运行日志。
汇总.json：本次查询数量和完成状态。

查询范围
固定并发 14；每个 SN 只查询第一页，pageSize=50，alarmType=0，不自动翻页。
接口返回总数大于实际导出数时，查询明细会标记“未完整导出”，日志和界面也会提醒。
告警时间和内容原样取自接口，保留时区以及 ↑/↓ 符号，不按电脑时区转换。
告警按请求完成顺序写入，同一 SN 的告警保持接口顺序，序号在整个结果中连续递增。
无告警的 SN 会在查询明细中记录；本次全部无告警时，告警列表仍保留表头。
CSV 使用带 BOM 的 UTF-8 编码，可用 Excel 打开，支持中文、俄文等字符。
若文本以 Excel 公式符号开头，会添加前导单引号，避免被当成公式执行。

停止与保存
“停止查询”会停止发起新请求，等待当前请求结束，保留已经写入的结果。
查询中关闭窗口也会先停止并保存。剩余 SN 在查询明细中记为“未查询”。
每次运行建立新文件夹，不自动续跑，不会覆盖此前结果。

账号保存与服务地址
账号密码仅在勾选后保存，使用 Windows 当前用户加密，存放于：
%LOCALAPPDATA%\FoxAlarmExport\
复制 EXE 或压缩包不会附带账号密码；其他电脑或 Windows 用户需要重新输入。
取消勾选后开始一次查询，会清除对应服务地址此前保存的信息。
登录接口使用与原工具一致的 MD5 密码参数；界面始终输入原始密码。
默认服务地址 https://www.foxesscloud.com，可在 config.json 中修改 domain。
lang 默认 en，与原工具相同；导出内容语言由服务器决定。
需要网络和该账号对 SN 的查询权限；无需另装 Python 或其他运行环境。
