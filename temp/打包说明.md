# CSV数据清理工具 - 打包说明

## 📦 打包步骤

### 1. 安装必要的依赖

首先确保安装了 Python 3.7+ 和 pip。

```bash
# 安装 PyInstaller
pip install pyinstaller

# 安装项目依赖
pip install -r requirements.txt
```

### 2. 打包成 EXE 文件

#### 方法一：使用配置文件打包（推荐）

```bash
pyinstaller build_exe.spec
```

#### 方法二：使用命令行直接打包

```bash
pyinstaller --onefile --noconsole --name "CSV数据清理工具" run_gui.py
```

### 3. 查找生成的 EXE 文件

打包完成后，可执行文件位于：
```
dist/CSV数据清理工具.exe
```

## 🎯 文件说明

- `run.py` - 原始命令行版本
- `run_gui.py` - 图形界面版本（用于打包）
- `requirements.txt` - Python 依赖包
- `build_exe.spec` - PyInstaller 打包配置
- `打包说明.md` - 本说明文档

## 🚀 使用方法

### 图形界面版本（run_gui.py）
直接运行：
```bash
python run_gui.py
```

### 命令行版本（run.py）
```bash
python run.py 文件路径.csv
```

### EXE 版本
双击 `CSV数据清理工具.exe` 即可运行

## ⚙️ 功能特性

1. ✅ 删除所有值都为 65535 的列
2. ✅ 对带数字后缀的列重新编号（如 Cel.Res.1, Cel.Res.2）
3. ✅ 保持原始列的相对顺序不变
4. ✅ 友好的图形界面
5. ✅ 实时处理日志显示
6. ✅ 自动保存为 `原文件名_cleaned.csv`

## 🔧 高级打包选项

### 添加应用图标
1. 准备一个 `.ico` 格式的图标文件（推荐尺寸：256x256）
2. 将图标文件放在 temp 目录下，命名为 `icon.ico`
3. 修改 `build_exe.spec` 文件中的 `icon=None` 改为 `icon='icon.ico'`
4. 重新打包

### 减小 EXE 文件大小

如果觉得打包后的文件太大，可以尝试：

```bash
# 使用 UPX 压缩（需要先下载 UPX）
pyinstaller --onefile --noconsole --upx-dir=UPX路径 run_gui.py

# 排除不需要的模块
pyinstaller --onefile --noconsole --exclude-module matplotlib run_gui.py
```

### 创建安装包（可选）

使用 Inno Setup 或 NSIS 创建 Windows 安装程序：
1. 下载并安装 Inno Setup
2. 创建安装脚本
3. 生成安装包

## 📝 注意事项

1. 打包后的 EXE 文件可能会被某些杀毒软件误报，这是正常现象
2. 首次运行 EXE 可能需要几秒钟启动时间
3. 建议在打包前先测试 run_gui.py 确保功能正常
4. 如果遇到打包错误，请检查 Python 版本和依赖包版本

## 🐛 常见问题

### Q: 打包后运行报错？
A: 确保所有依赖都已安装，并且 spec 文件中的 hiddenimports 包含了所有必要的模块。

### Q: 界面显示异常？
A: 检查系统字体是否支持"微软雅黑"，可以修改 run_gui.py 中的字体设置。

### Q: 文件太大？
A: 使用 `--upx-dir` 选项进行压缩，或考虑使用虚拟环境打包以减少不必要的依赖。
