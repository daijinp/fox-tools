# 南非停电通知 3.0 测试配置

实际配置填写在 `.env`；它已被 Git 忽略。`.env.example` 是不含密钥的可提交模板。

这里仅保存执行测试时需要输入或切换的值。代码中已经确定的表名、字段名、Job Handler、业务规则、重试策略等，不再作为环境变量；统一记录在 [`【代码分析】roulette-test测试信息收敛.md`](../docs/【代码分析】roulette-test测试信息收敛.md)。

## 已复用的配置

MySQL、SSH 账号和私钥继续使用现有配置：

```text
config.json
```

不要把这些敏感信息复制进 `.env`。

## 还需要补齐的内容

需要填写：

- 实际测试环境、部署版本和部署时间
- 测试电站的 `plant_id`、`block_id` 和 `device_id`
- 是否确认该设备可安全接收通知和执行强充

向开发或运维确认：

- EskomSePush Token 日配额
- XXL-JOB 管理台登录信息；Job ID 由测试时按 Handler 自动查询
- 账号/权限不足时，对应环境的访问授权

Token、XXL-JOB 密码和测试账号密码只写入本地 `.env`，不要发送给我，也不要放进截图或测试报告。

## Mock 说明

本轮不使用外部 Mock Server，因此 `.env` 不保存 Mock 开关和地址。模拟数据直接填写到 XXL-JOB 的 `eskomPushMessageTestJob` 任务参数中。

## 不再放进 `.env` 的信息

以下内容属于分析结论或测试记录，不是运行配置：

- 数据库表名和字段名
- Job Handler 名称、执行器端口和日志保留天数
- 强充提前时间、恢复规则、去重规则
- API 重试、错误码处理和同步数量上限
- 页面路径、联系人、APM/日志入口说明

页面观察结果、业务确认和缺陷证据后续直接记入测试方案或测试报告。APM 不是第一轮测试的必需项；XXL-JOB 日志或应用日志至少能查看一种即可。
